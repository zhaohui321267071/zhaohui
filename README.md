# 每日打卡 App

一个无需构建步骤的轻量级打卡网页应用，可在浏览器中记录每日完成情况、备注、连续打卡天数、累计打卡次数和本月打卡天数。

## 功能

- 每天只能打卡一次，避免重复记录。
- 支持填写 120 字以内的今日备注。
- 自动统计连续打卡、累计打卡和本月打卡。
- 使用浏览器 `localStorage` 保存记录，刷新页面后数据仍然保留。
- 支持一键清空所有本地记录。

## 本地运行

直接打开 `index.html`，或在仓库根目录启动一个静态服务器：

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。
